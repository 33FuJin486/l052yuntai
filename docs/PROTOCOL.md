# 串口协议说明

本协议由原始 Python 程序与 STM32 `app.c` 共同确认。

## 物理参数

- 串口：运行时扫描并选择，不写死 COM6。
- 默认波特率：115200。
- Python 读超时：0.01 秒；写超时：0.05 秒。
- 默认发送频率：30 Hz，可配置 1–100 Hz；建议保持 10–30 Hz。
- 编码：ASCII。

## 帧格式

```text
[error_x,error_y]\n
```

要求：

- `[`、`,`、`]` 为固定字符。
- 数字使用十进制有符号整数。
- 字段间没有空格。
- 末尾为 LF (`0x0A`)，不是 CRLF。

示例：

```text
[35,-18]\n
```

## 坐标语义

```python
error_x = target_center_x - frame_center_x
error_y = frame_center_y - target_center_y
```

- 目标位于画面右侧：X 为正。
- 目标位于画面左侧：X 为负。
- 目标位于画面上方：Y 为正。
- 目标位于画面下方：Y 为负。
- `[0,0]` 是合法误差，表示目标处于画面中心。

STM32 当前在进入 PID 前对两轴误差取负号：

```c
PID_Calc(&pid_yaw, -(float)err_x);
PID_Calc(&pid_pitch, -(float)err_y);
```

桌面端不得额外反转符号。

## 目标丢失和安全停车

```text
[9999,9999]\n
```

STM32 收到后：

1. `target_yaw_speed = 0`。
2. `target_pitch_speed = 0`。
3. 复位 Yaw PID。
4. 复位 Pitch PID。

桌面端在以下情况使用该帧：目标丢失、暂停发送、停止识别、紧急停止、正常退出前停车。

## 状态变化与失联保护

- 桌面端按固定频率发送最新误差。
- 目标从存在变为丢失或从丢失变为存在时，立即发送一次，不等待下一个周期。
- STM32 视觉模式超过 500 ms 没有收到可解析帧时，两轴归零并复位 PID。
- 串口写失败后桌面端停止发送、关闭端口，视觉识别继续运行。
