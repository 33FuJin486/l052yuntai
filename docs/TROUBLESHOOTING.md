# 常见错误处理

## 软件无法启动

- 发布时必须复制整个 `dist/云台视觉跟踪系统`，不能只复制 EXE。
- 检查杀毒软件是否隔离 PyTorch/Qt DLL。
- 在构建机使用全新 Python 3.10 虚拟环境重建。
- 保留 PyInstaller 构建日志，检查隐藏导入或 DLL 错误。

## 模型不存在或加载失败

- 默认位置必须为 EXE 同级 `model/best.pt`。
- 用界面重新选择 `.pt` 文件。
- 当前模型保存版本为 Ultralytics 8.4.103，优先用相同版本加载。
- 类别编号超出模型类别表时，修改检测类别或输入 `None`。

## 摄像头不存在、被占用或中途拔出

- 点击“刷新摄像头”。扫描在后台线程执行，不会阻塞界面。
- 关闭占用摄像头的软件。
- 从 640×480 开始测试；部分驱动不会接受任意分辨率。
- 中途拔出达到 10 次连续读取失败后，识别停止并释放设备；重新插入后刷新并打开。

## 串口不存在、被占用或中途拔出

- 点击“刷新串口”，确认设备管理器中的 COM 编号。
- 软件会标注扫描到的 CH340/CH341 设备；没有任何 COM 口时会显示驱动帮助提示。
- “未发现串口”不等同于驱动一定缺失：还需检查设备供电、USB 数据线、USB 接口和 Windows 设备管理器。
- 使用 CH340/CH341 时，点击“CH340/CH341 驱动帮助”可在确认后打开[沁恒官方 CH341SER 驱动页](https://www.wch.cn/downloads/ch341ser_exe.html)。软件不会自动下载或安装驱动。
- 关闭串口助手和 IDE 监视器。
- 确认波特率为 115200。
- 写入失败后软件关闭串口、停止发送，视觉画面继续；重新连接即可。

## 云台方向相反

- 先保持桌面端误差公式不变。
- 当前 STM32 在 PID 前对 X/Y 取负号。方向问题应在 STM32 电机方向或其 PID 输入处统一修正，不能在两端重复取反。

## 云台抖动或延迟

- 发送频率建议 10–30 Hz，不要无限制按推理帧率发送。
- STM32 当前 PID 死区为 40 像素、滤波系数 0.6。
- 检查串口是否堆积、摄像头缓冲是否生效。
- 多目标频繁切换属于“最近中心目标”策略的已知限制；需要更稳定锁定时应新增跟踪 ID，但这属于后续算法变更。

## CUDA 不可用

- CPU 模式是受支持的默认回退。
- CUDA 版需要与 PyTorch 匹配的 NVIDIA 驱动和单独构建环境。
- 不要把 `device="cuda"` 写死；以界面设备状态为准。
